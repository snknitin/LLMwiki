## Practical Sequence

1. Build one writing desk with structured output and manual export.
2. Build one bot with SQLite, scheduler, and reversible actions.
3. Build one audit pipeline with deterministic evidence checks.
4. Reuse those primitives in an agency workbench.
5. Attempt real-time rooms, browser agents, or multi-agent crews only after the simpler engine is battle-tested.
