# Maintainer Desk

**Difficulty:** HARD  
**Track:** AI as Agency  
**Partners:** CLOUDFLARE · CONVEX · LINKUP

## Brief

An agent operations desk for a real open source repo: a triager labels and reproduces issues, a review agent does first-pass PR review, a docs agent patches stale pages, a community agent drafts replies, and a manager routes it all with a judge gating anything before it posts to GitHub.
