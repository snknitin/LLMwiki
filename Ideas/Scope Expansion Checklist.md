# Scope Expansion Checklist

Current project specs assume a local, single-user prototype with user-supplied inputs. **Do not change the recommended local tech stack merely because this checklist exists.**

Activate this review only before adding other users, public hosting, open-source distribution, shared datasets/assets, external posting or messaging, payments, monetization, or a public product claim.

At expansion time, review:

- data, media, model, font, and dependency licenses;
- trademarks, attribution, redistribution, and generated-output rights;
- platform API terms, quotas, app review, and automation rules;
- privacy, authentication, encryption, retention, deletion, and user consent;
- medical, financial, biometric, aviation, accessibility, child-safety, or other domain obligations;
- payment custody, tax, refunds, geographic availability, and consumer disclosures;
- moderation, abuse prevention, rate limits, audit logs, incident response, and support;
- deployment, observability, backups, migrations, multi-tenancy, and cost controls.

Add only the minimum release-layer changes justified by the actual expansion. Preserve the battle-tested personal core and its data formats whenever possible.
