# Best 12 repos for AI engineers to optimize LLM speed, memory, and GPU usage 👇

> **Source:** [Stanislav Beliaev](https://www.linkedin.com/in/ACoAACPwVh4B9nRz6TBuOrJzp8I7gScS9bvv968) · Co-Founder & CTO at GetFluently.App (YC W24), ex Nvidia · 6mo

> [View post on LinkedIn](https://www.linkedin.com/feed/update/urn:li:activity:7419716961229737984/)

## Post

Best 12 repos for AI engineers to optimize LLM speed, memory, and GPU usage 👇

1:// vLLM (⭐ 66.5k)
https://lnkd.in/dv5Qt53g
The industry standard for high-throughput LLM serving. Continuous batching, strong GPU utilization. If you're deploying at scale, start here.

2:// llama. cpp (⭐ 92.2k)
https://lnkd.in/dqPVimrQ
Port of Llama in C/C++. The standard for running LLMs on consumer hardware locally.

3:// Ollama(⭐ 158k)
https://lnkd.in/dbGG2xvR
The easiest way to run Llama 3, Mistral, and other models locally. Clean dev experience for fast experimentation.

4:// Hugging Face Transformers (⭐ 154k)
https://lnkd.in/dzMSUSdu
Access to nearly all major model architectures and inference pipelines. The foundation of modern ML.

5:// Pytorch (⭐ 96.2k)
https://lnkd.in/d5A3ESNn
The core deep learning framework. Essential when you need custom optimization and low-level control.

6:// Unsloth (⭐ 50k)
https://lnkd.in/dRs8gcmP
Fine-tuning and RL for LLMs. Trains 2x faster with 70% less VRAM.

7:// exo (⭐ 38.9k)
https://lnkd.in/dwsTMMNn
Run your own AI cluster at home. Distributed inference across multiple devices.

8:// FastChat (⭐ 39.3k)
https://lnkd.in/dJnTsKr7
Open platform for training, serving, and evaluating LLM chat systems. Great for research and prototyping.

9:// llm. c by Karpathy (⭐ 28.5k)
https://lnkd.in/d89aJBW8
LLM training and inference in raw C/CUDA. Minimalist and educational.

10:// MLC LLM (⭐ 21.8k)
https://lnkd.in/dtbkiQFX
Universal LLM deployment engine. Runs on any platform via ML compilation.

11:// Flash Attention (⭐ 21.4k)
https://lnkd.in/dgBPj5wM
Fast, memory-efficient attention mechanism. Used by many other tools under the hood.

12:// whisper. cpp (⭐ 45.4k)
https://lnkd.in/dVdmUzex
High-performance port of OpenAI's Whisper in C/C++. Fast audio transcription.

What would you add to the list?
