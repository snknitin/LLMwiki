## Post

Unlimited-OCR: Latest Breakthrough In Open-Source Document AI

Baidu released Unlimited-OCR in June and is quickly becoming popular for one-shot large document parsing. Built on DeepSeek-OCR, it excels at fast, accurate processing of long documents on local. 

Here are the deets:
What it can do: Reads entire 40+ page PDFs or books in one pass; outputs clean Markdown with tables, formulas, reading order, and layouts preserved. 
Key Tech: Uses R-SWA attention for constant memory and stable speed on long outputs (no slowdown). 
Performance: ~93.9% on OmniDocBench (SOTA); strong multilingual support. 
Adoption: Over 2.1 million downloads and ~14,800 GitHub stars in the first month. 

Unlimited-OCR is the latest standout open-source model to watch in #AI, proving small, efficient models can rival or beat bigger systems on practical tasks while staying truly accessible.
