## Post

When AI coding assistants became more capable, I worried that the book I’d spent a couple of years working on would become obsolete. But actually, “Software Engineering for Data Scientists” is more useful now than it was when I finished it in 2024!

The reason: I covered all the best practices you need to know to write great data science code, but I didn’t include anything about Python syntax. These days, Claude can write all your Python functions with correct syntax. But unless you know what to ask it for, it won’t necessarily include tests, logging, error handling, and so on - all the things you need to make your code robust, reproducible and ready for production. You can learn how to get better code out of your AI from my book.
