## Post

Claude Code is a game-changer. But after a few marathon sessions, I hit a frustrating wall:

Every time I needed to check context usage or costs, I had to break my flow. Worse? I’ve committed code to the wrong branch more times than I’d like to admit because Claude Code doesn't make it obvious where you are.

In my BC (Before Claude) era, I used to spend hours in my terminal with Starship showing me exactly what I need: directory, git branch, and language runtimes. But stepping into Claude Code AD (Agent Domini) felt like flying blind.

So I built CShip.

It’s a fast, lightweight Rust CLI that acts as a bridge between your existing Starship config and Claude Code.

Why use CShip?

- Zero Config: If you use Starship, it just works. One line to install. One binary. No dependencies.

- Stay in Flow: Reuses your existing Starship themes, Nerd Fonts, and Hex colors inside the Claude environment.

- Context Intelligence: Visual indicators for context window usage with custom thresholds that change color when you’re nearing the limit.

- Quota Monitoring: Live tracking for session costs and those dreaded 5h/7d usage limits.

- Branch Awareness: Never commit to main by accident again.

The best tools are the ones that get out of your way and let you build. CShip is open source and ready to ship.
