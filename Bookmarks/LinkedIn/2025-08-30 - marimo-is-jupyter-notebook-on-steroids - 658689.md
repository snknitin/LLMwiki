## Post

Marimo is Jupyter Notebook on steroids. And since last week there's also a cloud version: Molab. It's just really really good, here's why:

The notebooks are...

- git friendly as .py files
- reactive and interactive
- executable as python scripts
- reusable, you can import functions/classes from others
- turnkey ready to easily query all kinds of data sources
- easily shareable as web pages or slides
- testable with pytest

With their functionality they replace jupyter, streamlit, jupytext, ipywidgets, papermill, and more all in go! And now with Molab in the cloud you start with a few clicks, get free compute, upload your own data files, share undiscoverable links.

The connection to your local machine is also easy. Download/upload the code easily via CLI. Molab is made to build data, ML and LLM solutions with a smooth developer experience. No more notebook vs. production code battles 💁🏽‍♂️

Marimo already has over 300k downloads per month. Molab will democratise access even more. No fancy machine needed.

Myles Scolnick, Akshay Agrawal, Vincent D. Warmerdam and about 150 other contributors are really knocking it out of the park with this open source project!
