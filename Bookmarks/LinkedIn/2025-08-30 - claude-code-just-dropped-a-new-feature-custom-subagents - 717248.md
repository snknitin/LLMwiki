## Post

Claude Code JUST dropped a new feature - custom subagents 🔥 You can now organize AI agents like a dev team.

Building AI agents used to mean wrestling with complex frameworks, managing multiple APIs, and spending days on orchestration logic.

Now, you can create specialized AI workers in minutes. Each one handles a specific task - code review, testing, deployment, documentation.

What makes this useful:

→ Simple setup: define your agent with natural language instructions
→ Focused agents: create agents for specific domains (frontend, backend, DevOps, etc.)
→ Easy coordination: agents work together without complex orchestration
→ Flexible scaling: start with one agent, add more as needed

Here’s an example workflow:

A 3-agent system for code quality:
→ Agent 1: Reviews code for security issues 
→ Agent 2: Generates comprehensive tests 
→ Agent 3: Updates documentation automatically
Tasks that typically require manual coordination now happen automatically.

You don't need deep AI expertise. If you can describe what you want in plain English, you can build it.

Try it today - just type /agents inside Claude Code to get started!
