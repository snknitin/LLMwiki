# GPU kernel programming is the hardest skill in AI engineering.

> **Source:** [Paolo Perrone](https://www.linkedin.com/in/ACoAAAWy1ToBOCCi0ildR12MNTXMvqvygTADf6c) · Shipping Production AI: Agents, Inference, GPU. Read by 1M+ AI engineers. · 2mo

## Post

GPU kernel programming is the hardest skill in AI engineering.

Most engineers treat the GPU like a black box.

Tokens go in. Latency comes out.

The kernel is someone else's problem.

Until it isn't.

Here's the path from black box to a $400K job:

1️⃣ CUDA from scratch
PMPP textbook. GPU Mode lectures. Every NVIDIA engineer started here.

2️⃣ Matrix multiplication optimization
Write a CUDA matmul that matches cuBLAS. The interview question that separates senior from staff.

3️⃣ FlashAttention from first principles
The kernel that changed inference economics. Most engineers use it. Few understand how it works.

4️⃣ Tensor Cores and mixed precision
FP8 training. NVFP4 inference. The formats cutting GPU bills in half.

5️⃣ Production inference at scale
vLLM. SGLang. TensorRT-LLM. Continuous batching. KV cache optimization. NCCL at 100K+ GPUs.

6️⃣ LLM-generated kernels
Meta's KernelLLM beats GPT-4o at writing CUDA. This section didn't exist a year ago.

Section 1 opens the black box.
Section 6 is how Meta trains at 100K+ GPUs.

One repo. Free. In the comments 👇
