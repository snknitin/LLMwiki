# I've read 25+ AI/ML books in 8 years.

> **Source:** [Shirin Khosravi Jam](https://www.linkedin.com/in/ACoAACAffBABmg0i0TxuEnNvNKeuiy2-Kq7k_Ds) · Sr. Data Scientist/ AI Engineer | 400k+ AI/ML Community | Data Science, RAG, AI Agents, & MLOps | Germany’s Top Female Voice in AI (Favikon) 🇩🇪 | Opinions are my own! · 10mo

> [View post on LinkedIn](https://www.linkedin.com/feed/update/urn:li:activity:7379783335528632320/)

## Post

I've read 25+ AI/ML books in 8 years. 

Only 11 would actually move the needle in production.

(I've shipped Data Science, MLOps, RAG systems, and AI agents)

Here's what actually matters:

📌 𝗠𝗮𝘁𝗵𝗲𝗺𝗮𝘁𝗶𝗰𝗮𝗹 𝗙𝗼𝘂𝗻𝗱𝗮𝘁𝗶𝗼𝗻𝘀

→ Mathematics of Machine Learning - Tivadar Danka
Understand the foundations with great intuitions!
🔗 Link - https://lnkd.in/d3g494VJ

→ ML with PyTorch and Scikit-Learn - Sebastian Raschka, PhD
Bridge theory to practice with both classical ML and deep learning.
🔗 Link - https://lnkd.in/dkBwkjBc

📌 𝗣𝗿𝗼𝗴𝗿𝗮𝗺𝗺𝗶𝗻𝗴 & 𝗦𝘁𝗮𝘁𝘀

→ Fluent Python - Luciano Ramalho
Write production-grade Python code.
🔗 Link - https://lnkd.in/dPzSFYmr
(skip it if you think you can learn better through courses)

→ Practical Statistics for Data Scientists - Bruce & Bruce
A/B test models and detect data drift.
🔗 Link - https://lnkd.in/dwtNNU4R

📌 𝗡𝗟𝗣 & 𝗟𝗮𝗻𝗴𝘂𝗮𝗴𝗲

→ Python NLP Cookbook - Antić & Chakravarty
Classical NLP for when RAG retrieves garbage.
🔗 Link - https://lnkd.in/dVPGPew6

→ NLP with Transformers - Tunstall, von Werra, Wolf
Understand what's under the hood of LLMs.
🔗 Link - https://lnkd.in/dqk62AQT

📌 𝗠𝗟 𝗦𝘆𝘀𝘁𝗲𝗺𝘀

→ Designing Machine Learning Systems - Chip Huyen
Be in the 13% that reach production.
🔗 Link - https://lnkd.in/dPXxKNgk

→ ML System Design Interview - Aminian & Xu
Think in patterns: scale from 1K to 100M users.
🔗 Link - https://lnkd.in/d_V98BW9

📌 𝗟𝗟𝗠𝘀 & 𝗔𝗴𝗲𝗻𝘁𝘀

→ AI Agents in Practice - Valentina Alto
Build agents that work in production.
🔗 Link -https://lnkd.in/d92bycbU

→ AI Engineering - Chip Huyen
LLMs in production: RAG, prompts, infrastructure.
🔗 Link - https://lnkd.in/dw_F-PtH

📌 𝗜𝗻𝗳𝗿𝗮𝘀𝘁𝗿𝘂𝗰𝘁𝘂𝗿𝗲

→ Designing Data-Intensive Applications - Martin Kleppmann
Your model is only as good as your infrastructure.
🔗 Link - https://lnkd.in/duWW2tD6

𝗠𝘆 𝗵𝗼𝗻𝗲𝘀𝘁 𝘁𝗮𝗸𝗲:
Pick 1-2 books. 
Build something small. 
Come back when you hit problems.

Detailed post on WHEN each saved me → Link in comments 👇

𝗪𝗵𝗮𝘁 𝗯𝗼𝗼𝗸𝘀 𝘀𝗵𝗮𝗽𝗲𝗱 𝘆𝗼𝘂𝗿 𝗷𝗼𝘂𝗿𝗻𝗲𝘆?

PS: There are many books out there, but these are the list of must read from my end. For learning LLMs as well there are multiple resources, so didnt include.
