# Stumbled on something interesting today — Claude's been building a implicit profile of me with a MEM...

> **Source:** [Pranam Kolari](https://www.linkedin.com/in/ACoAAAAMFt0BfYVjxw6oR5SjaIXOL4yngT4W8sM) · Founding.. · 4mo

## Post

Stumbled on something interesting today — Claude's been building a implicit profile of me with a MEMORY.md file (CLAUDE.md is explicit) across sessions. After a multi-day spike, and a few retrospectives together, my file had this:

<verbatim>

Role: Founder/technical lead at 37degreesN. Builds health-tech and data tooling.

Technical depth: Deep. Understands architecture, databases, deployment, GCP/Firebase. Can navigate consoles, run CLI commands, modify org policies. Not a passive consumer — actively steers technical decisions.

Working style:
Moves fast. Expects results, not explanations of what will be done.
Asks "why" questions that probe root causes, not symptoms.
Values poka-yoke thinking — every failure should produce a safeguard.
Prefers seeing data (SQL queries, funnel analysis, git logs) over opinions.
Will correct wrong hypotheses directly ("it's not API, I am sure about this").
Wants action items split into what HE can do vs what Claude should do.
Prefers start/stop/continue framing for process improvement.
Asks for design docs before building — reviews and iterates before code.

Communication preferences:
Short, direct responses. Lead with the answer.
Show the command to run, not a paragraph about what the command does.
When multiple options exist, present them as a table with tradeoffs.
Don't ask permission for obvious next steps — just do them.
DO ask before: deploying, pushing, deleting, or architectural decisions.

</verbatim>

If you're using Claude regularly, check your MEMORY.md. If you don't see anything; Ask: "What do you know about me?". If you are comfortable sharing, share it here.

Curious how different these get across you all, and how teams of agents view you, in contrast with teams of us humans.
