Microsoft just dropped a hands on course for MCP (Model Context Protocol)

Here’s what it covers-

	•	Introduction to Model Context Protocol (MCP)
	•	MCP Core Concepts
	•	MCP Security Best Practices
	•	Building Your First MCP Server
	•	Developing, Testing & Deploying MCP Apps with Real Tools and Workflows
	•	Advanced MCP: Secure, Scalable, and Multi-modal AI Agents
	•	Contributing to MCP: Tools, Documentation, and Code
	•	Lessons from MCP Early Adopters
	•	MCP Development Best Practices
	•	MCP in Action: Real-world Case Studies
	•	Building AI Agents in Visual Studio Code (Hands-on Labs)
	•	MCP Motivation and Quick Demo
	•	MCP Architecture and Transport Layer
	•	MCP Sampling, Composition, and Discovery
	•	Introduction to FastMCP (SDK for building MCP servers in Python)
	•	Use Case Contexts (e.g., integrating with various tools)
	•	MCP Tools, Resources, and Prompts
	•	Deployment Theory and Practice (including Docker and Google Cloud)
	•	Testing and MCP Inspector
	•	Building Custom MCP Clients
	•	Real-world Integrations (e.g., Azure, Dataverse, API Management)
	•	Building Browser Automation Agents with MCP
	•	Bonus: Adaptive Learning Apps and AI Documentation Workflows
