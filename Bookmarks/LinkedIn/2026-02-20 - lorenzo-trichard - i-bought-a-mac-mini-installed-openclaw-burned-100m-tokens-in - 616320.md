# I bought a Mac Mini. Installed OpenClaw. Burned 100M tokens in 7 days.

> **Source:** [Lorenzo Trichard](https://www.linkedin.com/in/ACoAADRPRE8BQ5EI3o-OZcjm6yvhsazZjQiSeUM) · Co-founder @ Kendle | Building growth marketing engines for the next tech wave | Web3 • AI • Fintech · 5mo

## Post

I bought a Mac Mini. Installed OpenClaw. Burned 100M tokens in 7 days.
That's when I realized two things:

- This thing works way harder than I expected.
- My API bill is going to kill me.

So I went deeper.

Installed Ollama. Loaded Qwen3 locally. Set up ClawRouter.
And that's when I understood the whole architecture.

ClawRouter is the brain behind the operation.
It decides which model handles which task — in real time.

Not every task needs a $0.03/token reasoning model. Not every task can be handled by a local SLM.

So clawrouter splits the work:

The reasoning model is the head. 
Claude Opus 4.6. Gemini 3 Pro. MiniMax 2.5
Strategy. Planning. Complex decisions.

The local SLM is the arm. 
Qwen3 on Ollama. Running on a $600 Mac Mini. 
Execution. Writing. Loops. Grinding. 24/7.

ClawRouter sits between the two and routes every task to the right model based on complexity.

Add the SKILL presets — custom instructions that make the small model perform like it's 10x its size — and suddenly you have something dangerous.

An AI agent that thinks like a premium model. 
Executes like a local machine. 
Runs nonstop. 
Costs almost nothing.

100M tokens in 7 days taught me the lesson. 
ClawRouter was the answer. 🦀
