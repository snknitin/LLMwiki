## Post

Jens Jorgenson's Design Ontology Spec is a YAML file that defines your product's nouns, verbs, and composition rules before any code gets written. Feed it as context to every LLM prompt and the model stops inventing a different object model per session. Without it, vibe coding produces the same cable-remote chaos … just generated faster. Fifteen minutes of pen-and-paper noun reduction saves hours of refactoring incoherent AI output.
