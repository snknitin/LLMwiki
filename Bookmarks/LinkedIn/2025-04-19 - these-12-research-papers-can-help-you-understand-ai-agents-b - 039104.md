## Post

These 12 research papers can help you understand AI Agents better

From frameworks to surveys, here's my best picks from 2024

📌 Frameworks and Models

1. Magentic-One by Microsoft
TLDR → Update to the Autogen framework, this paper discusses a generalist multi-agent system for solving open-ended web and file-based tasks across a variety of domains.
https://lnkd.in/gYgzZgwc

2. Agent-oriented planning in a Multi-Agent system
TLDR → A unique framework utilizing Meta-agent architecture for clever planning in a multi-agent system
https://lnkd.in/gxJJjT3G

3. KGLA by Amazon
TLDR → Amazon proposes a Knowledge graph-enhanced agent framework for better knowledge retrieval across various domains
https://lnkd.in/g4xjDC9X

4. Harvard University's FINCON
TLDR → Researchers propose an LLM-based multi-agent framework with conversational verbal reinforcement for diverse FINancial tasks.
https://lnkd.in/g22UmxXe

5. OmniParser for Pure Vision-Based GUI Agent
TLDR → A Multi-agent approach for UI Navigation for GUI-based AI Agents.
https://lnkd.in/gFHJuSxb

📌 Experimentation/Analysis

1. Can Graph Learning Improve Planning in LLM-based Agents? by Microsoft
TLDR → This paper highlights an experiment done to prove that graph learning can improve AI Agents using GPT-4 as their core LLM.
https://lnkd.in/gRY7QTx5

2. Generative Agent Simulations of 1,000 People by Stanford University and Google DeepMind

TLDR → This paper shows clever experimentation which proves that AI Agents can clone 1,000 people using 2hr audio
https://lnkd.in/gM3s8_9m

3. An Empirical Study on LLM-based Agents for Automated Bug Fixing
TLDR → ByteDance's experimentation to understand which llms are best suited for agentic automated bug fixing
https://lnkd.in/gSennV8V

4. Google Deepmind's Improving Multi-Agent Debate with Sparse Communication Topology
TLDR → Google shares experimentation where they improve Agentic communication with limited information sharing
https://lnkd.in/gsax7ujE

📌 Case study/Survey

1. LLM-based Multi-Agents: A survey
TLDR → The paper surveys the progress and challenges of LLM-based Multi-Agent Systems (LLM-MA), highlighting their applications in problem-solving and world simulation
https://lnkd.in/gcXneu6T

2. Practices for Governing Agentic AI Systems by OpenAI
TLDR → OpenAI shares 7 tips to create safe and accountable AI Agents for businesses
https://lnkd.in/gaVQT4rU

3. The Dawn of GUI Agent: A case study for Computer use of Sonnet 3.5
TLDR → This paper tests the usability of Anthropic's Computer use across various domains
https://lnkd.in/gHeXNrPT
