# 10 useful beginner tips if you’re a non-technical new to claude code:

> **Source:** [@0xDesigner](https://x.com/0xDesigner) · 2026-01-05 · 👍 556 · 💬 31 · 🔖 932 · 👁 39043

> 🔗 [View tweet on X](https://x.com/0xDesigner/status/2008018043205460106)

## Tweet Content

10 useful beginner tips if you’re a non-technical new to claude code:

1. use plan mode (shift + tab)
2. write “ultrathink” in your prompts to make claude smarter
3. be selective with ultrathink, it slows you down and fills the context window
4. use “/“ and explore all the slash commands
5. hit “esc” twice to undo code or restore conversation from a different point
6. after claude writes code simply ask it “run dev” to see what it made locally
7. type “/init” to create project instructions
8. use claude code chrome extension (start claude in the terminal with “claude —chrome”) so it can see issues for itself
9. pick up an old thread by running “claude —resume”
10. hit “esc” while claude it working to interrupt it

bonus: use claude code in the cursor terminal, hit [ctrl + shift + ~] to open a new terminal and then drag the terminal shell with your mouse to the center of the window and you now have full screen claude code in cursor.
