# for anyone that likes the Remote-SSH feature in VS Code: Hermes Desktop now does the same thing for...

> **Source:** [@witcheer](https://x.com/witcheer) · 2026-07-22 · 👍 98 · 💬 11 · 🔖 88 · 👁 19202

> 🔗 [View tweet on X](https://x.com/witcheer/status/2079979538902302837)

## Tweet Content

for anyone that likes the Remote-SSH feature in VS Code: Hermes Desktop now does the same thing for your agent :)

pick any host you already have SSH access to and the app starts Hermes on it, tunnels it back, and your chats, files, sessions and integrated terminal all run on the remote machine. 

hosts from your `~/.ssh/config` show up in a dropdown, and every client-remote OS combination works.
