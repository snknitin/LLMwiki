## Tweet Content

So I've been experimenting more with using Hermes Agent in Buzz, and I developed a few open source skills that I thought might be useful:

-hermes-in-buzz:  Skill to get the Buzz CLI and authentication set up when trying to connect a remote Hermes instance to your local Buzz app through the gateway. Hand this to your remote Hermes to get things set up right

-buzz-media-attachments: For an agent to attach video and media files in Buzz, it requires a specific format, so this skill teaches the agent to do that

Still experimenting in buzz a lot, so keep an eye on this repo  because I'll probably be adding to it!
