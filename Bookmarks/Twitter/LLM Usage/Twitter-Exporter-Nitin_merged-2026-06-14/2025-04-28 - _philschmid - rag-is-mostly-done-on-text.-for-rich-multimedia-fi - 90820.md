# RAG is mostly done on text. For rich multimedia files like PDFs it often requires complex pre-proces...

> 🔗 [View tweet on X](https://x.com/_philschmid/status/1916743982639390820)

## Tweet Content

RAG is mostly done on text. For rich multimedia files like PDFs it often requires complex pre-processing steps and dropping relevant graphics from your context. By combining 
@GoogleDeepMind
 Gemini 2.5 with a multimodal Embedding model like Cohere's latest Embed v4 you can unlock vision RAG and avoid image-to-markdown conversion.

 Directly retrieves & understands complex images (slides, charts, graphs, infographics).
 Skips prone image-to-markdown steps, preserving rich visual information.
 Combines Gemini Flash 2.5 (vision LLM) with Cohere Embed v4 (retrieval).
 Delivers accurate, detailed answers by reasoning over the content of complex graphics.
 Full code example available via Colab notebook to try it yourself.

Big kudos to 
@Nils_Reimers
 for the excellent end-to-end example, and to 
@cohere
 for their powerful Embed v4 model!
