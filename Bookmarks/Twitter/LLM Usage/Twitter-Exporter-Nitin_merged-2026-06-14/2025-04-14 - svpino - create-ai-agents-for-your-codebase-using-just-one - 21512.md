## Tweet Content

Create AI agents for your codebase using just one prompt.

This is pretty incredible! (This repo hit #2 on GitHub trending).

Potpie is an open-source platform that lets you build custom agents that understand your codebase and can automate any development task.

These are not "white-labeled", out-of-the-box, one-size-fits-all agents. These are *your* agents. They know *your* codebase. They are tailored to *your* use cases — anything from software architecture to root cause analysis.

For example, here is a prompt to create an agent:

"You are a custom agent specialized in generating detailed integration tests for this Python repo using Pytest. Refer to existing tests in the /test directory and generate new integration tests using the same format."

That's all it takes!

These custom agents ingest your codebase and build a knowledge graph—a mental model of your system that lets them:

 • Understand your code
 • Navigate your project's structure
 • Reason about relationships & dependencies
 • Focus on the right context, every time

I've been talking about knowledge graphs forever, and this is a great use case for them.
