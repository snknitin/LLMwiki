I'm in the process of learning about Agents 


@lilianweng
 wrote a great post covering the key components of an LLM-powered autonomous agent system. Here is a short overview of how each piece builds on an LLM:

• Planning: The agent can break down complex tasks into subtasks. It can also learn from its past mistakes to improve future actions. 

• Memory: Memory is broken down into short-term and long-term memory. Short-term memory is the in-context learning - aka, this is how you're prompting the LLM. Long-term memory enables the agent to store previous actions/information and use it in the future. This is done by using vector stores, like 
@weaviate_io
, for fast retrieval. 

• Tool Use: The agent can call external APIs and tools, like a calculator, code interpreter, and more.
