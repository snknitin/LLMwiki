# I just built my second brain with Hermes Agent.

> **Source:** [@dr_cintas](https://x.com/dr_cintas) · 2026-07-17 · 👍 151 · 💬 19 · 🔖 250 · 👁 16032

## Tweet Content

I just built my second brain with Hermes Agent.

It remembers people, companies, projects, and decisions. It pulls from meeting notes, docs, anything I feed it, and cites the source every time.

It's this repo called Gbrain, open-sourced by Y Combinator president Garry Tan.

install it by pasting this into Hermes:
  "Install Gbrain following the instructions at 
http://
github.com/garrytan/gbrain. Set up the embedding provider, then run gbrain init and gbrain doctor to verify."

Add the MCP server so Hermes can call it directly:
  "Add the Gbrain MCP server and reload."

The graph builds itself. Pattern matching on the people and companies already in your notes. 31 points more precise than plain vector search, by their own benchmark.

The data from the video is made up so I could show you how it works.

Hermes' memory remembers our conversations. Gbrain remembers my world.

Open source. Runs local, no server, no Docker.

Here’s the repo for those interested: 
https://
github.com/garrytan/gbrain
