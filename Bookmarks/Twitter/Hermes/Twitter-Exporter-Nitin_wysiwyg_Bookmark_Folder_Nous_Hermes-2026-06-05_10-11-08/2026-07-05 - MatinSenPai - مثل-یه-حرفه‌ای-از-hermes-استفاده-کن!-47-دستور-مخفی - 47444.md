Use Hermes like a pro! 47 secret Hermes commands you need to learn

A few of the cool things you'll see in this video:
Command /learn: With this command, you give Hermes a document or website, it reads it and fully learns it! The next time you ask a question, it answers based on the data it has learned. It also creates a personal Skill for you!
Command /goal: You define a long-term goal for it, and it remembers throughout the entire development process that it must stick to that goal.
Commands /snapshot and /rollback: Just like save/load in games. You save a point in your work, and if the AI messes up, you can go back to before with one button!
Command /yolo: Turning off Hermes's safety brakes!
Command /suggestions: If you're stuck and don't know what the next step is for your project (or your life), you use this, and it suggests smart things you can do
Command /moa: Combining the power of multiple AIs together (Mixture of Agents) to solve impossible bugs. With multiple parallel models and one aggressive model
Commands /browser and /bg: Bypassing search restrictions of all browsers for the agent with CDP (Chrome DevTools Protocol). This one's absolutely amazing
Command /pet: You'll have to see this one for yourself...  We turn Batman into a terminal pet
