# okay why did nobody tell me about state.md for claude code?

> 🔗 [View tweet on X](https://x.com/SearchForRyan/status/2032574688149328103)

## Tweet Content

okay why did nobody tell me about state.md for claude code?

i've been stuck wondering why a project i build on daily was taking 8-10 mins to make changes

turns out claude was reading EVERYTHING (all my code) before it made a change.

i added state.md, architecture.md (alongside my claude.md) and bam, 8,000 tokens to ~1,000 tokens and from 8 mins to ~ 60 seconds.

claude.md wasn't enough in this instance annnnd i'm so happy lol

For new features it’ll go into plan mode but for ongoing changes, updates, tweaks, it doesn’t need to do that. 

It’s been working well so far!

It’s a client/admin portal for my wife’s business

So I’ve got it set up to do two things:

1. If I ask for a new feature it’ll read the code base in a more streamlined way and then plan the changes 

2. If it’s just a tweak or fix, it doesn’t do that, it just refers to state and architecture files

yep same! All I say is ‘update state.md with what we did here today’

Claude.md is still sub 100 lines and state.md will be edited every couple of week to get rid of old things
