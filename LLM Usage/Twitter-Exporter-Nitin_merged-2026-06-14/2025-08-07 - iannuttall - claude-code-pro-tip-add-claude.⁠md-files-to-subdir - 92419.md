Claude Code pro tip: Add CLAUDE.⁠md files to subdirectories

This is the unsung hero of making CC less "dumb". Instead of one giant rule, each dir can have their own:

/src/components/CLAUDE.⁠md
/src/db/CLAUDE.⁠md

Gives Claude more precise context and makes a HUGE difference
