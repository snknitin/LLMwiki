Insanely fast whisper - now with a CLI

You can now translate/ transcribe 100s of hours of data across 99 languages! - all from your terminal.

Here's how you can use it:
1. Install requirements
pip install transformers, accelerate, optimum

2. Grab the transcribe py file and run:
python transcribe py --file_name <filename or URL>

That's it! 

Bonus: This CLI will support the Distil-Whisper checkpoints we'll be releasing tomorrow too!
