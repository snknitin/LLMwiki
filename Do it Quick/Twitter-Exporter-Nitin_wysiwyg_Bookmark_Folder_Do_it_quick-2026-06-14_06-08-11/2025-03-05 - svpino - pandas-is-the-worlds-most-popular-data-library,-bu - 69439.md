Pandas is the world's most popular data library, but it's slow, and many libraries have significantly improved over it.

But people don't want to migrate their code base. Pandas is extremely popular, and there aren't enough incentives to make changes unless necessary.

The good news is that you don't have to change anything to achieve many times the performance you are getting today.

FireDucks is a multi-threaded, compiler-accelerated library with a fully compatible pandas API.

It's up to 48x faster than Pandas, and you don't have to touch anything to use it.

You have two options to start using FireDucks:

1. import fireducks.pandas as pd, or
2. Run your code as-is: python -mfireducks.imhook yourfile[.]py
