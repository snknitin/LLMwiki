# Learning Request Template

Copy this into a new file in `Kaggle/Inbox`. Do not put passwords, tokens or private datasets here.

```markdown
---
title: My topic or competition
kind: reference
status: queued
topics: NLP, evaluation
updated: 2026-09-26
---
# My topic or competition

Source: https://www.kaggle.com/...
Type: learning / completed competition
Question: What do I want to understand or reproduce?
Time available: 20 minutes
Desired output: ADHD-friendly digest; for competitions, top-ten coverage and consolidated comparison.
```

Ask Hermes to process one queued request using the project's `DAILY_REVIEW.md`. Scheduling is currently off. A writeup that cannot be read remains marked missing; it is never filled with guessed methods.
