# Kaggle Learning Lab

**Start with one 20-minute lesson.** Open the topic map in [Kaggle Learning Lab](https://spark-07a8.tail4a1242.ts.net:8772/) and choose a topic.

## Your three spaces

| Space | What you get |
| --- | --- |
| [[Learning/Learning Index]] | Advanced topics explained in short layers, exercises and source links. |
| [[Competitions/Competitions Index]] | Completed competitions, solution comparisons and honest top-ten coverage. |
| [[Journey/Daily Brief]] | Your next action, suitable competition research and Grandmaster journey. |

## Add something to learn

1. Create a Markdown note in `Kaggle/Inbox` using [[Templates/Learning Request]]. Paste the Kaggle Learn, competition or writeup URL and the question you want answered.
2. Ask Hermes or Codex to process the request using the project's `DAILY_REVIEW.md`; the planned Hermes `spark-fast` schedule is currently disabled.
3. Open the dashboard. It refreshes its Markdown library automatically. You can also ask Codex to process the request now.

Already have a good Markdown explanation? Save it directly in Learning or Competitions. No HTML conversion is needed. Use [[Templates/Learning Digest]] for consistent metadata.

## Reading modes

Read the next action and five-minute digest first. Expand the deeper explanation when you want it. Finish the small exercise before selecting another topic. The graph connects shared topics; it is a navigation map, not a claim that a prerequisite has been mastered.

## What stays authoritative

All learning content lives here in Markdown and syncs through Obsidian. Spark serves a private Tailscale website. The browser's read markers are local to that browser; they do not represent Kaggle completion or medals. Activity reports show source timestamps and preserve unknowns.

**Scheduling is currently off.** The future daily review will use Hermes with `spark-fast` after testing. The Spark website runs independently. See [[Operations]] for controls and limitations.
