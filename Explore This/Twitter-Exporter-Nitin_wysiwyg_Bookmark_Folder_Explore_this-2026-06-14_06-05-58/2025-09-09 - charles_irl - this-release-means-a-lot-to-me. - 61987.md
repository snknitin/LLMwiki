# This release means a lot to me.

> **Source:** [@charles_irl](https://x.com/charles_irl) · 2025-09-09 · 👍 227 · 💬 9 · 🔖 70 · 👁 46893

> 🔗 [View tweet on X](https://x.com/charles_irl/status/1965458286066761987)

## Tweet Content

This release means a lot to me.

I learned to code in notebooks -- MATLAB, R, Julia, Python. I even tried to learn C from notebooks once! 

I've always preferred more interactive and literate programming. That's one reason why I love 
@modal
 so much -- it brings that interactivity to cloud-native development.

But there was still a gap. Sometimes I just wanted a notebook. And I wanted it "serverlessly", in the sense that I didn't need to spin up a Jupyter Hub server and fiddle with networking and security. Modal's core Functions and Sandboxes had that extra layer of friction.


@ekzhang1
 and team have more than filled that gap. Even in this early stage -- hell, even after the first few sprints -- Modal Notebooks is an incredible platform for easeful, interactive development of multimedia, data-intensive, and educational code.
