# Wow! Meta dropped an open NotebookLM recipe: NotebookLlama 🔥

## Tweet Content

Wow! Meta dropped an open NotebookLM recipe: NotebookLlama 

It uses L3.2 1B/ 3B for pre-processing the PDF, L3.1 70B for Transcript creation, L3.1 8B for re-writes and Parler TTS for Text to Speech 

Step 1: Pre-process PDF: Use Llama-3.2-1B-Instruct to pre-process the PDF and save it in a .txt file.

Step 2: Transcript Writer: Use Llama-3.1-70B-Instruct to write a podcast transcript from the text

Step 3: Dramatic Re-Writer: Use Llama-3.1-8B-Instruct model to make the transcript more dramatic

Step 4: Text-To-Speech Workflow: Use parler-tts/parler-tts-mini-v1 and bark/suno to generate a conversational podcast

There's still some rough edges, but it already sounds pretty fire - Link to notebook in the comments
