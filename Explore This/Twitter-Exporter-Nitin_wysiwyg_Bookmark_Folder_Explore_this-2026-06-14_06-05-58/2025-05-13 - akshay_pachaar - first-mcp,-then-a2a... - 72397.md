First MCP, then A2A...

...now AG-UI completes the protocol stack.

While MCP connected Agents to tools and A2A connected Agents to other Agents, AG-UI bridges the gap between Agents and users.

This new open-source protocol serves as the missing link between your agentic backend and user-facing UI apps.

Here's how it works:

- Client fires a POST request to the agent endpoint
- It then opens a single HTTP stream to get live events.
- Each event has a type and some metadata
- The agent streams these events in real time.
- UI updates the moment each event arrives
- UI can send its own events + context back to the agent
