## Article Content

This major update brings over ****150 improvements****, focusing on security, first part of local Gemma rollout, tasks, and streamlined UI with less clutter.

### 🚀 New Capabilities

- ****Local Gemma for Model Routing (Experimental)****: Initial support for local Gemma models, currently used to power intelligent model routing. The team is working toward full local model execution in future updates Use    ****gemini gemma ****to set up and ****/gemma**** to check status.

To enable: Use ****/settings**** or ****experimental.gemma: true**** in ****settings.json****.

![](https://pbs.twimg.com/amplify_video_thumb/2049571941544022016/img/M6z77xt1I_rp6Yi4.jpg)

- ****Task Tracker (Experimental)****: Maintain an internal, persistent list of tasks so Gemini CLI can better monitor progress on complex objectives.

To enable: Add ****experimental.taskTracker: true**** to your ****settings.json****.

https://x.com/JackWoth98/article/2049574123630940418/media/2049573709489520640Task list kept via Task Tracker feature

- ****Compact Tool Output****: Tool outputs (file reads, search text, list directory) are now displayed in a cleaner, structured format for better readability. No more tool calls spamming your output!

![](https://pbs.twimg.com/amplify_video_thumb/2049566689151623169/img/BO_tOA3-dHl-IDQM.jpg)

Compact tool outputs, no more tool boxes spamming output!

- ****Topic Narrations****: Gemini CLI now outputs topics which act as headings so you can quickly see what the agent is up to instead of the agent spamming “I’ll do this…”. Topic updates are now narrated by default and more descriptive across all agents.

![](https://pbs.twimg.com/amplify_video_thumb/2049567132648910848/img/b12MZPE8_LQ__xcA.jpg)

Topics are now outputted as headers: (i.e. "Researching Memory System: Researching the memory system to explain how it works.")

- ****MCP Resource Support****: Finalized support for Model Context Protocol (MCP) resources.

### 🧠 Smarter Memory & Context

****Tiered Memory System:**** A complete rebuild of the agent's memory architecture. The agent now persists project context by directly editing Markdown files across four distinct layers, replacing the legacy save_memory tool with a more transparent and flexible approach:

- ****Project****: Team-shared conventions, architecture rules, and workflows stored in ****./GEMINI.md ****(committed to your repo).
- ****Subdirectory****: Highly specific overrides or instructions scoped to a part of your project (e.g., ****./src/GEMINI.md****).
- ****Private****: Project-specific personal notes and machine-local setups stored in a private MEMORY.md index (not committed to the repo).
- ****Global****: Cross-project personal preferences and coding styles that follow you into every workspace, stored in ~/.gemini/GEMINI.md.

💭****Auto Memory (Experimental):**** Automatically extract reusable skills from your past sessions. This background service combs through idle session transcripts to identify recurring procedural patterns and hard-won fixes.

![](https://pbs.twimg.com/amplify_video_thumb/2049548254061424640/img/V8iO9IK7Vdat39mP.jpg)

Run /memory inbox to view auto generated skills based on past session history.

****How it works:**** A specialized extraction agent analyzes your local chat history (focusing on sessions with 10+ messages) to find common workflows. It then drafts these patterns as new ****SKILL.md**** files or patches to existing ones.

****Review Inbox:**** Use the new ****/memory inbox ****command to review these drafts. You can inspect the logic, see which sessions inspired the skill, and choose to promote it to your permanent workspace or global skills library.

To enable: Use the /****settings**** dialog or add "experimental": { "autoMemory": true }` to your ****settings.json****.

- ****Real-time Suggestions****: A new file watcher detects and suggests files in the "****@"**** menu the moment they are created.
- ****Session Persistence****: Added better support for session persistence and JSONL-based streaming for chat recordings.

### 🛠️ CLI & UX Improvements

- ****New Commands****: Added**** /new**** as a quick alias for starting fresh sessions.
- ****Better Accessibility****: Added new colorblind-friendly themes based on GitHub’s design system.
- ****Native Notifications****: Integrated OSC 777 support allows the CLI to send native desktop alerts for completion or required action.
- ****Interaction Refinements****: Mouse-clicking support for multi-line answers and improved scroll momentum.

### 🛡️ Security & Trust

We've introduced stricter validation for shell commands and a core tools allowlist to help prevent command injection and unintended executions.

- ****Secure Workspace Loading****: Enforced trust in headless and IDE environments and more secure handling of project configurations (`.env` files).
- ****Enhanced Sandboxing****: New controls and centralized path utilities for restricted environments like Docker or macOS Seatbelt.
- ****Credential Safety****: Improved logging for keychain fallbacks to better protect your sensitive information.

### ⚡ Performance & Reliability

- ****Memory Optimization****: Significant reductions in memory usage for DevTools and large output stream handling.
- ****Offline Readiness****: ****ripgrep**** binaries are now bundled, enabling lightning-fast searches without an internet connection.
- ****Fixes****: Resolved issues with heredocs, line endings in ignore files, and IDE integration.

A huge thank you to the ****40+ contributors**** who made this release possible! ❤️
